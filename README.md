## Introduction

This repository contains a practical example of CSS nesting using SCSS, based on educational materials from Harvard University. It demonstrates how nested selectors can organize styles and apply formatting to HTML elements within a parent element.

## Topics Covered

- Introduction to CSS nesting
- SCSS nested selectors
- Parent and child element relationships
- Nesting paragraph (`p`) selectors inside `div`
- Nesting unordered list (`ul`) selectors inside `div`
- Applying font sizes, text colors, and nested styles

## Practical Example

The project demonstrates how to style elements inside a `div` using nested SCSS rules:

- Paragraphs inside the `div` receive blue text.
- Unordered lists inside the `div` receive green text.
- The parent `div` defines a font size of `18px`.

## Learning Approach

The HTML example contains elements both inside and outside a `div`, while the SCSS stylesheet demonstrates how nested selectors target elements within the parent container.
